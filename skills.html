工程能力

能力描述来自 MultiCA、KasioRpc 与 LogScope 的实际开发，覆盖业务服务端、网络基础设施和可观测性工具。

网络协议与 RPC

  • 基于 TCP/KCP 与 Protobuf 构建双传输 RPC 链路，理解可靠传输与实时性之间的取舍。
  • 实现长度前缀协议、粘包/半包处理、消息尺寸校验、心跳保活、单向调用与服务注册分发。
  • 能够围绕连接建立、请求路由、超时取消与连接关闭设计完整生命周期。

游戏服务端

  • 具备服务端权威的多人同图对战开发经验，支持多客户端并发接入及 PVE/PVP 事件处理。
  • 实现网络中断重连、玩家状态恢复、怪物自动寻路、战斗结算和跨客户端公告广播。
  • 关注房间、玩家、单位与战斗事件的边界拆分，保证状态变更可追踪、可校验。

C++20 与异步并发

  • 熟悉 RAII、智能指针、模板、lambda、移动语义与现代 STL，能够组织可维护的模块边界。
  • 使用协程、io_context 线程池与 strand 编排异步任务，控制回调时序并减少共享状态竞争。
  • 理解原子状态机、条件变量、有界队列及任务生命周期，能够排查死锁、竞态和悬空访问。

稳定性与可观测性

  • 围绕超时、重试、断线、异常隔离和资源回收设计失败路径，避免局部故障放大。
  • 使用 Prometheus 指标、结构化日志与诊断命令观测请求耗时、错误率、积压和容量水位。
  • 能够从运行现象回溯连接、协程、队列和数据层，形成定位—修复—回归验证闭环。

数据检索与存储

  • 使用 SQLite WAL/FTS5 构建日志索引，兼顾写入吞吐、全文检索与单机部署成本。
  • 支持结构化条件、全文关键词与自然语言查询，能够设计多数据源路由和统一结果模型。
  • 理解索引、缓存、分页和容量治理对查询延迟及资源占用的影响。

Python 绑定与跨语言协作

  • 基于 CPython C API 暴露 C++ RPC 能力，处理参数转换、异常映射、引用计数和 GIL 协作。
  • 将 C++ 异步回调安全桥接为 asyncio Future，使 Python 侧保持自然的 await 调用体验。
  • 能够设计稳定的跨语言接口，减少运行时细节对上层业务代码的侵入。

AI 工程化

  • 在日志分析中组合规则、轻量模型与大模型级联，按置信度和成本选择处理路径。
  • 实现基于 ReAct 的诊断流程，管理工具调用、上下文预算、失败降级与结果可解释性。
  • 强调 AI 能力的边界控制：保留确定性规则兜底，避免外部模型故障阻塞核心流程。

工程质量与交付

  • 熟悉 Linux/WSL、CMake、vcpkg 与 Git，能够完成依赖管理、构建调试和多模块协作。
  • 通过单元测试、集成测试、压力测试及 TSAN/ASAN 验证协议边界、并发安全和资源释放。
  • 具备 CI 与 Python manylinux wheel 交付实践，关注可复现构建、版本兼容和发布质量。
